# OneClickInstaller

Установщик популярных программ для Windows «в один клик»: окно со списком, галочки,
кнопка «Установить» — и всё ставится через `winget`. Без установки самого
установщика, без браузера и без «далее-далее-готово».

## Скачать

Готовый exe — в разделе **Releases**: https://github.com/GBsine/OneClickInstaller/releases

Один файл, ничего доустанавливать не нужно. Внутри уже лежат список программ и иконки.

## Как запустить

1. Скачать `OneClickInstaller.exe` и запустить.
2. Подтвердить запрос UAC (нужны права администратора — иначе часть установщиков
   не поставится молча).
3. Отметить программы (двойной клик по строке тоже переключает галочку).
4. Нажать **«Установить выбранное»**.

Выбор, язык и режим запоминаются в `%LOCALAPPDATA%\OneClickInstaller\settings.json`,
журналы установок пишутся в `%LOCALAPPDATA%\OneClickInstaller\logs`.

## Что умеет

- Поиск по названию, описанию, категории и ID.
- Фильтр по категориям.
- «Выбрать всё» / «Снять всё» (работают по текущему фильтру).
- Тихая установка (`--silent`) — можно выключить галочкой, если установщик
  должен показать свои окна.
- Кнопка **«Остановить»** — прерывает очередь после текущей программы.
- Живой прогресс: видно, что идёт скачивание (с процентами) или установка.
- Уже установленные программы определяются одним запросом к winget и пропускаются.
- Статус по каждой программе: установлено / уже установлено / ошибка.
- Переключатель языка **Русский / English** прямо в окне (выбор запоминается).

## Требования

- Windows 10 или 11.
- Компонент **App Installer** (в нём живёт `winget`). В свежей Windows он уже
  есть; если нет — Microsoft Store → «App Installer».
- Интернет — только для скачивания самих программ. Интерфейс и иконки работают офлайн.

## Про антивирус

Exe собран как обычное .NET WinForms-приложение: не распаковывает файлы, не
запускает PowerShell, не прячется. Проверка Microsoft Defender на финальной сборке:
`Scanning ... found no threats`.

Файл не подписан сертификатом, поэтому SmartScreen при первом запуске может
показать «Неизвестный издатель» — это ожидаемо для самосборных программ. Полностью
убирается только подписью кода (code signing certificate).

## Сборка из исходников

Нужен только встроенный в Windows компилятор `csc.exe` (.NET Framework 4.x),
ничего доустанавливать не надо.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "native\build.ps1"
```

Скрипт создаёт иконку, упаковывает `apps.json` и `icons\*.png` в ресурсы exe,
компилирует `native\OneClickInstaller.exe` и копирует его на рабочий стол.

Исходник приложения — `native\OneClickInstaller.cs` (один файл, C# WinForms).
Рядом `native\app.manifest` (DPI + совместимость с Windows 10/11).

## Как добавить свою программу

1. Найти точный ID:
   ```powershell
   winget search имя_программы
   ```
2. Открыть `apps.json` и добавить строку:
   ```json
   { "id": "Vendor.App", "name": "Название", "category": "Категория", "desc": "Короткое описание", "desc_en": "Short description" }
   ```
3. Пересобрать exe (см. выше).

Категория — любая своя, список категорий в фильтре строится автоматически.
Для новой категории можно добавить перевод в `native\OneClickInstaller.cs`
(словарь `CatsEn`), иначе в английском режиме она останется как есть.

## Файлы

| Файл | Назначение |
|------|------------|
| `native\OneClickInstaller.cs` | исходник приложения (C# WinForms) |
| `native\build.ps1` | сборка exe |
| `native\app.manifest` | манифест (DPI, совместимость) |
| `apps.json` | список программ |
| `icons\` | иконки программ (`<id>.png`), можно заменить своей картинкой |
| `OneClickInstaller.ps1` | старая версия на PowerShell (оставлена для истории) |
| `Start.cmd` | запуск старой версии |

## Если что-то не ставится

- Смотрите строку с кодом ошибки в журнале: `код 0` — успех,
  `код -1978335189` — уже установлено.
- Некоторые установщики не поддерживают `--silent` — снимите галочку
  «Тихая установка».
- Корпоративные политики/антивирус могут блокировать установку — проверьте
  журнал и события установщика.
- Список ID проверялся на момент создания; если пакет переименовали, найдите
  новый ID через `winget search` и поправьте `apps.json`.
