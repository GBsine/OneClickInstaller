# OneClickInstaller

Установщик программ «в один клик» для Windows: окно со списком, галочки, кнопка
«Установить» — и всё ставится через `winget`. Без установки самого установщика,
без браузера и без «далее-далее-готово».

## Вариант в одном файле (exe)

В папке уже собран `C:\Users\zk\Desktop\OneClickInstaller.exe` — один файл, внутри
которого лежат скрипт, `apps.json` и все иконки. Интернет нужен только для
скачивания самих программ (winget), иконки и интерфейс работают офлайн.

При первом запуске (или если exe обновился) он распаковывает рабочую копию в
`%LOCALAPPDATA%\OneClickInstaller\app` и запускает её. `settings.json` и `logs\`
тоже живут там.

**Пересобрать после правки `apps.json` или иконок:**

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "build\build.ps1"
```

Скрипт заново создаёт иконку, упаковывает `OneClickInstaller.ps1`, `apps.json` и
`icons\` в `payload.zip`, компилирует `build\OneClickInstaller.exe` и копирует его
на рабочий стол. Нужен только встроенный в Windows `csc.exe` (.NET Framework),
ничего доустанавливать не надо.

Файл не подписан сертификатом, поэтому SmartScreen/антивирус может спросить
подтверждение при первом запуске — это нормально для самосборного exe.

## Как запустить

1. Двойной клик по **`Start.cmd`**.
2. Подтвердить запрос UAC (нужны права администратора — иначе часть установщиков
   не поставится молча).
3. Отметить программы (двойной клик по строке тоже переключает галочку).
4. Нажать **«Установить выбранное»**.

Выбор запоминается в `settings.json`, журнал пишется в `logs\`.

## Что умеет

- Поиск по названию, описанию, категории и ID.
- Фильтр по категориям.
- «Выбрать всё» / «Снять всё» (работают по текущему фильтру).
- Тихая установка (`--silent`) — можно выключить галочкой, если установщик
  должен показать свои окна.
- Кнопка **«Остановить»** — прерывает очередь после текущей программы.
- Статус по каждой программе: установлено / уже установлено / ошибка.
- Переключатель языка **Русский / English** прямо в окне (выбор запоминается).

## Требования

- Windows 10 или 11.
- Компонент **App Installer** (в нём живёт `winget`). В свежей Windows он уже
  есть; если нет — Microsoft Store → «App Installer».
- Интернет.

## Как добавить свою программу

1. Найти точный ID:
   ```powershell
   winget search имя_программы
   ```
2. Открыть `apps.json` и добавить строку в список:
   ```json
   { "id": "Vendor.App", "name": "Название", "category": "Категория", "desc": "Короткое описание", "desc_en": "Short description" }
   ```
3. Перезапустить установщик.

ID должен быть точным (`winget search --id <id> -e` находит пакет). Категория —
любая своя, список категорий в фильтре строится автоматически.

## Файлы

| Файл | Назначение |
|------|------------|
| `Start.cmd` | запуск (двойной клик) |
| `build\` | исходники упаковки: `Launcher.cs`, `build.ps1`, готовый exe |
| `OneClickInstaller.ps1` | сам установщик (PowerShell + WinForms) |
| `apps.json` | список программ |
| `icons\` | иконки программ (`<id>.png`), можно заменить своей картинкой |
| `settings.json` | сохранённый выбор, создаётся автоматически |
| `logs\` | журналы установки |

## Если что-то не ставится

- Смотрите строку с кодом ошибки в журнале: `код 0` — успех,
  `код -1978335189` — уже установлено.
- Некоторые установщики не поддерживают `--silent` — снимите галочку
  «Тихая установка».
- Корпоративные политики/антивирус могут блокировать установку — проверьте
  журнал и события установщика.
- Список ID проверялся на момент создания; если пакет переименовали, найдите
  новый ID через `winget search` и поправьте `apps.json`.
